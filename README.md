# Skip React Starter

Esqueleto mínimo para iniciar uma aplicação React no Skip.

## Incluído

- React 19 e TypeScript;
- Vite;
- Tailwind CSS;
- biblioteca shadcn/ui;
- roteamento e estrutura inicial de páginas;
- lint e formatação com Oxlint/Oxfmt.

## Executar

```bash
pnpm install
pnpm dev
```

## Comandos

```bash
pnpm dev
pnpm build
pnpm lint
pnpm format
pnpm preview
```

## Escopo

Este repositório é intencionalmente um **starter**, não um produto final. Use como ponto de partida, substitua a página inicial e configure autenticação, dados, testes e regras de segurança conforme o projeto.
